# Замеры маршрутизации: до и после

Снято `tools/simulate.py --sample 1500 --all --policy <политика> --json` на одном зерне.
JSON-файлы рядом — сырые данные по каждому сценарию.

## Политики

Политика — это модель поведения пользователя при прогоне по графу вопросов.

- **benign** — «ни одного тревожного признака»: выбирается вариант, который не задевает
  ни один red flag и ни одно правило «к специалисту». Это и есть лёгкая травма из
  замечания заказчика (ушиб пальца), и главная метрика.
- **unknown_heavy** — то же, но в 30% случаев пользователь отвечает «не знаю».
- **uniform** — равномерный случайный выбор. Сильно завышает долю тревожных ответов
  (у каждого скринера 1–2 экстренных варианта из 4–5), поэтому как метрика продукта
  бесполезна; оставлена как стресс-тест.

## Результат

| политика | исходы ДО | исходы ПОСЛЕ | вопросов задано |
|---|---|---|---|
| benign | `refer_specialist` **100%** | `self_rehab` 93.3%, `recovery_plan` 6.7%, **направлений 0%** | 20.9 → 16.3 |
| unknown_heavy | `refer_specialist` **100%** | `refer_specialist` 89.4%, `self_rehab` 3.9%, `recovery_plan` 6.7% | 20.9 → 17.7 |
| uniform | `refer_specialist` 99.9% | — (стресс-тест, не метрика) | 5.4 |

Вопросов объявлено: 23.3 → 23.1 в среднем. Объявленное число почти не изменилось, потому
что вместо шести вопросов экстренного каскада появился один скринер `g_alarm`, а сами
вопросы остались в файле — они просто больше не задаются, если тревожных признаков нет.
Поэтому смотреть нужно на «задано», а не на «объявлено».

## Как это читать

**Главное:** человек без тревожных признаков больше не уходит к врачу ни в одном из 15
сценариев. Было ровно наоборот — 100% направлений после 21 вопроса.

**unknown_heavy остался высоким намеренно.** «Не знаю» перестало вести к врачу только на
вопросах про обстоятельства и анамнез (`g_history`, `g_sleep`, `g_prior_eval`,
`g_program`, `g_comorbid`). На наблюдаемых опасных признаках — деформация, цвет и
температура конечности, онемение, возможность опоры, горячий сустав, признаки ТГВ —
ответ «не знаю» по-прежнему означает осмотр. «Не знаю, холодная ли у меня стопа» — это
не то же самое, что «не знаю, мешает ли боль спать». Это осознанное отступление от
правила «все ответы „не знаю“ ведут в самореабилитацию» и **требует подписи врача**.

**Сокращение опроса — 21 → 16 вопросов, а не до 6–8, как предполагалось в плане.**
Дальнейшее сокращение упирается в клинически значимые вопросы: для голеностопа это
восемь вопросов дифференциальной диагностики (локализация боли, возможность опоры,
середина стопы, отёк, нестабильность, ахилл, механизм, динамика). Их объединение — это
медицинское решение о чувствительности, а не механическая правка, поэтому оно выведено
в вопросы к врачу, а не сделано самостоятельно.

## Как перезамерить

```bash
uv run python -m tools.simulate --sample 1500 --all --policy benign --json
```

Барьеры против регресса — в `tests/scenarios/test_prod_routing.py`: благополучный путь
не должен давать направлений ни в одном сценарии, таблица `MUST_REFER` фиксирует ответы,
которые обязаны вести к врачу, и ограничен максимум заданных вопросов.
